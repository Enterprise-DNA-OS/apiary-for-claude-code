# Why no front end

This is a database and operating recipes for Claude Code, Codex, OpenCode or Cursor. The agent reads and writes through one CLI. Private HTML reports and paperwork are read-only exports, not an application or a replacement field tablet.

MyApiary supplies field data entry, jobcards and synchronisation. This base has no mobile capture, offline sync, mapping, photos, device integration, shared logins or drag-and-drop planner. Use your existing field records and import them. Enterprise DNA can scope a field workflow and connect it to the owned database.

PGlite supports one local process at a time. PostgreSQL supports a shared database, but the free base does not provide tenant isolation, user permissions, an audit log or a backup service. Configure controls and recovery before production use. Do not serve generated records publicly.

Exports are portable records. Official HiveHub filings, processor systems, food safety decisions and device software remain separate. There is no automatic submission or send path.
